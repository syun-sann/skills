# IB 中文 A 卷一文本分析与学术评论工具 (paper1-drafter)

专门针对 IB DP 语言 A（文学 / 语言与文学）卷一：引导题文本分析（Paper 1: Guided Textual Analysis / Commentary）的专业技能与结构化工作流。

全文输出严格遵循规范现代标准汉语（简体中文），语言典雅、克制、思辨，全面对标 IB 官方 Level 7（满分 20/20）评分准则。

---

## 使用方法

### 1. 分步引导模式（推荐）
适用于需要先确认分论点框架再生成全文的场景：
> “请帮我分析这篇 IB 中文散文：[粘贴文本] 引导题：[输入引导题]”  
> *(AI 将首先执行第一步，输出 3 个三维互斥分论点，待用户确认或调整后再生成第二步六段式全文)*

### 2. 直接成文模式
适用于需要快速一键生成完整分析范文的场景：
> “请直接为这篇文本撰写完整的 IB 中文 A 卷一分析文章：[粘贴文本]”  
> *(AI 将连续输出第一步分论点与第二步六段式完整学术评论)*

### 3. 定向微调模式
适用于已有初稿、需要针对特定段落或维度进行优化的场景：
> “请在第3段深化对自然意象的分析” 或 “请增强第5段辩证补充段的批判力度”

## 详细流程与规范

### 第一步：提炼三维互斥核心分论点 (Step 1)
- **三维分类学**：
  - **维度一（叙述视角与语态）**：内聚焦/全知视角、叙述视距推移、冷峻白描/反讽语调。
  - **维度二（修辞、词汇与意象）**：词汇语义场聚类、感官通感、延伸隐喻与象征系统。
  - **维度三（篇章结构与时空张力）**：时空蒙太奇、二元对立并置、叙事突转与高潮。
- **公式**：`[策略机制] + [即时审美/修辞效果] + [核心主旨与读者效应]`

---

### 第二步：撰写六段式学术分析全文 (Step 2)

| 篇章部分 | 对应段落 | 核心写作规范与论证要领 |
| :--- | :--- | :--- |
| **一、开头段** | 第 1 段 | 明确文体、语境、中心论点（Thesis），**明确带出三个分论点**，确立学术基调。 |
| **二、主体分析段** | 第 2 段 (分论点1)<br>第 3 段 (分论点2)<br>第 4 段 (分论点3) | **严格贯彻 PEEL 三阶细读微模型**：<br>1. **引用**：精准微观嵌入 1–2 处原文字句。<br>2. **分析**：深度解构选词内涵义、修辞张力、感官机制。<br>3. **作用**：升华至读者心理契约与核心主题。 |
| **三、辩证补充段** | 第 5 段 | **冲刺 Level 7 辨析力的核心**：<br>客观指出手法/视角背后的内在局限（如叙事盲区、情感过载、二元简化），采用“固然……然而……”等平衡句式，深化全文论证张力。 |
| **四、结尾段** | 第 6 段 | 综合三维与辩证思考，回扣引导题，给出形而上或文化哲学层面的深度收束。 |

---

### 第三步：定向精准编辑与深化优化 (Step 3)
- **深度拓展**：细化微观词汇内涵义，展开多重隐喻层次。
- **语体消杀**：根除第一人称感性抒情，统一为规范学术书面语。
- **辩证强化**：更犀利地剖析艺术手法必然伴随的表现力代价。
