# Standard British English Guide for NUS Admissions

The National University of Singapore (NUS) and Singaporean academic institutions strictly adhere to **Standard British English** spelling, grammar, and vocabulary conventions.

---

## 1. Key Spelling Conventions

| Category | British English (Use) | American English (Avoid) | Application Context Examples |
| :--- | :--- | :--- | :--- |
| **-ise / -isation** | realise, recognise, organise, prioritise, optimise, specialised | realize, recognize, organize, prioritize, optimize, specialized | "I organised a seminar", "optimise algorithms" |
| **-our** | colour, behaviour, rigour, honour, neighbour, labour | color, behavior, rigor, honor, neighbor, labor | "academic rigour", "computational behaviour" |
| **-re** | centre, theatre, metre, fibre | center, theater, meter, fiber | "data centre", "research centre" |
| **-ence (nouns)** | defence, licence, practice (noun) | defense, license, practice (noun) | "cybersecurity defence", "a driving licence" |
| **-se (verbs)** | practise (verb), license (verb), advise (verb) | practice (verb), license (verb), advise (verb) | "practise coding daily" |
| **-ll- doubling** | travelled, modelling, cancelling, counselling, enrolment | traveled, modeling, canceling, counseling, enrollment | "data modelling", "upon enrolment" |
| **-ae / -oe** | foetus, leukaemia, encyclopaedia | fetus, leukemia, encyclopedia | "medical research", "biomedical study" |
| **-ogue** | dialogue, catalogue, analogue | dialog, catalog, analog | "constructive dialogue" |
| **Miscellaneous** | programme (academic/software is accepted as program/programme), enquiry, draught | program (US for all), inquiry, draft | "degree programme", "academic enquiry" |

## 2. Academic & University Terminology

| Concept | Standard British / Commonwealth (Use) | Americanism (Avoid) |
| :--- | :--- | :--- |
| University Level | "at university", "tertiary education" | "in college", "in school" |
| Courses / Units | "modules", "degree programme", "course of study" | "classes", "courses" (for single subjects) |
| Field of Study | "read Law", "read Computer Science", "study Economics" | "major in Law", "pursue a major" |
| High School Context | "Junior College (JC)", "High School", "Secondary School" | "sophomore/junior/senior year" |
| Standard Tests | "sit an examination", "take an examination" | "take a test" |
| Mathematics | "maths" | "math" |
| Practical Training | "internship", "attachment", "work placement", "practicum" | "externship", "practicum" |
| Academic Staff | "lecturer", "tutor", "professor", "faculty members" | "prof", "teachers" (for university) |

## 3. Punctuation & Style Nuances

### A. Quotation Marks & Punctuation Placement
- Place punctuation (periods, commas) **outside** quotation marks unless the punctuation is inherently part of the original quotation:
  - *Correct (UK)*: He described the project as 'pioneering', which inspired my interest.
  - *Avoid (US)*: He described the project as "pioneering," which inspired my interest.

### B. Single vs. Double Quotation Marks
- Use single quotes (`'...'`) for specialized terms, coined phrases, or direct speech. If there is a quote within a quote, use double quotes (`"..."`).

### C. Oxford (Serial) Comma
- In British English, the Oxford comma is optional and used primarily when necessary to resolve ambiguity. Keep phrasing clean and unencumbered.

### D. Acronyms & Abbreviations
- Do not use full stops in capitalised acronyms: *NUS*, *AI*, *IoT*, *GPA*, *O-Level*, *A-Level*, *IB*.
- Contractions with the same last letter as the full word omit periods in British style: *Dr*, *Mr*, *St* (not *Dr.*, *Mr.*).

## 4. Tone & Register

- **Understated Confidence**: British academic prose favors measured, objective claims over boastful superlatives.
  - *Instead of:* "I was without a doubt the most outstanding programmer in my entire state."
  - *Use:* "I placed first among 300 competitors in the State Computing Olympiad."
- **Active Precision**: Eliminate passive bloat without becoming overly informal.
  - *Instead of:* "It was observed by myself that the model was failing."
  - *Use:* "I noticed the model overfitting on noisy training samples."
