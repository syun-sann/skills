# ZhLanLit-Paper 参考资源架构指南 (References Overview)

本目录为 **ZhLanLit-Paper** 技能的核心知识库与深度参考资源，采用**双卷并行、四位一体**的模块化对称架构设计：
- **`paper1/`**：专门服务于【模式一】IB DP 中文 A 卷一（引导题单文本分析）任务。
- **`paper2/`**：专门服务于【模式二】IB DP 中文 A 卷二（两部文学作品比较学术论文）任务。

---

## 目录结构总览

```
references/
├── README.md                         # [本文件] 知识库导航与索引
├── paper1/                           # 卷一（Paper 1）引导题单文本分析专项
│   ├── framework.md                  # 方法论：三维互斥分类学、PEEL细读模型、第5段辩证与学术语体
│   ├── templates.md                  # 模板库：标准 4 部分 / 6 段式段落模板、分论点公式与微调策略
│   ├── exemplars.md                  # 范文库：散文《山林与时间的遗痕》与专栏《算法时代的数字游牧》满分范文
│   └── research.md                   # 研报库：官方标准解读、Level 7画像、四大失分陷阱与时间管理
└── paper2/                           # 卷二（Paper 2）双作品比较学术论文专项
    ├── framework.md                  # 方法论：双维度交叉对比模型、求同析异四维归因与学术衔接词库
    ├── templates.md                  # 模板库：标准 4 部分 / 8 段式双维度对比模板、立论公式与微调策略
    ├── exemplars.md                  # 范文库：余华《活着》vs古华《芙蓉镇》Level 7 满分范文及考官解析
    └── research.md                   # 研报库：官方标准（Criteria A-D, B2核心）、配对矩阵与时间管理
```

## 模块功能与调用指引

| 模块类别 | 目标文件 | 核心适用场景与内容摘要 |
| :--- | :--- | :--- |
| **Paper 1 方法论** | [`paper1/framework.md`](paper1/framework.md) | 需要深入理解视角、修辞、篇章三维互斥分类学；查询 PEEL 细读微模型或查阅高阶批评术语时使用。 |
| **Paper 1 写作模板** | [`paper1/templates.md`](paper1/templates.md) | 撰写或指导用户撰写 6 段式文本评论时，获取标准的段落起承转合结构与填空式模板句式。 |
| **Paper 1 满分典范** | [`paper1/exemplars.md`](paper1/exemplars.md) | 查看文学（散文）与非文学（文化批评专栏）两套完整的 20/20 满分范文及考官逐项评语。 |
| **Paper 1 深度研报** | [`paper1/research.md`](paper1/research.md) | 查阅 IB 官方评分标准、分级描述、考场时间分配（SL 75 min / HL 135 min）与避坑指南。 |
| **Paper 2 方法论** | [`paper2/framework.md`](paper2/framework.md) | 深入理解双维度交叉对比模型；查阅第 4 段与第 7 段求同析异“四维归因体系”及学术衔接词库。 |
| **Paper 2 写作模板** | [`paper2/templates.md`](paper2/templates.md) | 撰写标准的 4 部分 / 8 段式比较学术论文，获取解题开头段、两组[作1+作2+对比段]及结尾升华段的标准模板。 |
| **Paper 2 满分典范** | [`paper2/exemplars.md`](paper2/exemplars.md) | 研读基于余华《活着》与古华《芙蓉镇》的完整 8 段式比较范文，查看段落映射与考官 20/20 满分剖析。 |
| **Paper 2 深度研报** | [`paper2/research.md`](paper2/research.md) | 查阅 Criteria A-D 深度解析（重点关注 B2 势均力敌与归因）、105 分钟时间分配及经典作品配对矩阵。 |
