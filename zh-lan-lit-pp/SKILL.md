# IB 中文 A 写作引擎（Paper 1 & Paper 2）

全文统一使用规范现代标准汉语（简体）、第三人称学术语域。严禁「我认为」「笔者觉得」。严格对标 IB Level 7（20/20）。

默认执行：先输出 Step 1（分论点），确认后再输出 Step 2（全文）。用户明确催促时一键连续输出。

## 模式路由

| 模式 | 判定特征 | 交付成果 |
| :--- | :--- | :--- |
| **Paper 1** | 单篇文本 + 引导题（散文/小说/诗歌/戏剧/非文学） | 6段式学术评论，1000–1400字 |
| **Paper 2** | 提到「试卷二」或需比较两部作品 | 8段式双维度比较论文，1200–1600字 |
| **微调** | 提供已有初稿 + 修改要求 | 骨架稳定前提下定向增删与语体升华 |

## Paper 1：六段式单文本分析

### Step 1 — 三维互斥分论点

从**形式机制 → 即时效果 → 主旨服务**的因果链提炼三个严格互斥的分论点：

| 维度 | 观察切入点 | 提炼句式 |
| :--- | :--- | :--- |
| **一：叙述视角与语调** | 内聚焦/全知视角、视距调控、克制/反讽语调、双重身份张力 | 作者通过[视角策略]，借助[语调机制]，引导读者在[留白/审美距离处]体会[深层主旨]。 |
| **二：词汇与修辞意象** | 对立语义场、感官通感、延伸隐喻与象征、句式修辞（排比/对偶/悖论） | 文本构建了[A与B两套对立意象群]，借助[修辞机制]，具象化展现了[核心冲突/哲理]。 |
| **三：篇章结构与时空** | 时空蒙太奇、二元对立并置、节奏突转（Volta）、环形闭合、留白 | 作者运用[结构策略]，将[时空/情境A]与[时空/情境B]并置，完成对[核心矛盾]的哲理定格。 |

非文学文本扩展：多模态图文分析（视觉定锚 Anchorage、显著性 Salience、图文接力 Relay）。

### Step 2 — 标准六段式架构

| 段落 | 功能 | 核心规范 |
| :--- | :--- | :--- |
| **第1段**（引言） | 体裁语境 → Thesis → 三维分论点 | 高屋建瓴，不陈情节 |
| **第2段**（维度一） | 视角与语调的 PEEL 细读 | Point → 微观嵌入引文 → Explain（内涵义/机制）→ Link（读者认知/主旨） |
| **第3段**（维度二） | 修辞意象的 PEEL 细读 | 同上，聚焦语义场对比与隐喻跨域映射 |
| **第4段**（维度三） | 篇章结构的 PEEL 细读 | 同上，聚焦时空蒙太奇、突转与留白 |
| **第5段**（辩证段）⭐ | 主要手法的**内在代价** | 「固然……然而……」句式；聚焦叙事盲区/情感过载/二元简化，**严禁场外说道** |
| **第6段**（结论） | 回扣引导题 + 形而上升华 | 综合三维 + 辩证，哲理收束 |

**PEEL 不合格信号**：大段抄录引文、仅贴手法名称（「作者用了比喻」）、辩证段批评作者思想觉悟。

完整示范见 `references/p1-examples.md`。

## Paper 2：八段式双作品比较论文

### Step 1 — 审题与双维度分论点

- **解题**：界定题目关键词的两层内涵（手法机制 + 审美效果/主旨功能）
- **Thesis**：两作在核心命题上共同的文学探索
- **分论点一（叙事机制维度）**：两个作家都使用了[手法/策略]来[回应题目/塑造效果]
- **分论点二（具象载体维度）**：两个作家将[核心命题]寄托于[具象事物/文化符号]，以[具象化主题/丰满人物/深化意蕴]

### Step 2 — 标准八段式架构

| 段落 | 功能 | 核心规范 |
| :--- | :--- | :--- |
| **第1段** | 解题 + 两作介绍 + Thesis + 两维分论点 | — |
| **第2段** | 分论点一·作品1细读 | 叙事节奏/视角/次要人物/情感温度 |
| **第3段** | 分论点一·作品2细读 | 「同样的……」「与之遥相呼应的是……」 |
| **第4段** ⭐ | 分论点一·**综合对比**（求同析异） | 手法机制之异 + 时代意图之异 |
| **第5段** | 分论点二·作品1细读 | 具象事物/象征的意涵与哲学 |
| **第6段** | 分论点二·作品2细读 | 「同样的……」 |
| **第7段** ⭐ | 分论点二·**综合对比**（求同析异） | 意象载体之异 + 哲学旨归之异 |
| **第8段** | 结论 | 统摄两维 + 时代/人性/文学超越性升华 |

**四大质量红线**：
1. **50/50 平衡**：两作篇幅与证据深度严格 1:1，严禁单边倾斜
2. **对比段不可缺失**：第4/7段必须展开深度对比，不得「两张皮」平行割裂
3. **四维深层归因**：手法机制之异、意象载体之异、时代意图之异、哲学旨归之异
4. **学术承转词**：「殊途同归」「各具机杼」「同中有异」「异曲同工」「互为表里」

完整示范见 `references/p2-example.md`。

## 经典作品备考配对速查

| 配对 | 核心共享母题 | 核心异同切入 |
| :--- | :--- | :--- |
| 余华《活着》vs 古华《芙蓉镇》 | 历史苦难中的生命韧性与温情希望 | 同：逆境温情 + 核心象征物；异：道家顺天释然 vs 民间清醒抗争 |
| 曹禺《雷雨》（蘩漪）vs 易卜生《玩偶之家》（娜拉） | 父权禁锢下女性觉醒与悲剧抉择 | 同：封闭家庭空间 + 道具象征；异：玉石俱焚的非理性毁灭 vs 清醒决绝的个人主义出走 |
| 鲁迅《狂人日记》/《祝福》vs 加缪《局外人》 | 社会对个体的道德审判与精神绞杀 | 同：冷漠看客 + 边缘人视角；异：启蒙主义「救救孩子」 vs 存在主义荒谬与澄明 |
| 沈从文《边城》vs 契诃夫《樱桃园》 | 田园牧歌式微与时代变迁的怀旧诗学 | 同：哀而不伤 + 核心象征物（白塔/樱桃园）；异：重塑民族自然人性 vs 贵族衰亡与现代性反讽 |
